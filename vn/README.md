# «Зарянка» — браузерный VN-прототип (эпизод 1) + PWA

Минимальный, без зависимостей, «движок» визуальной новеллы на чистом
HTML/CSS/JS. Это **proof**: сценарий эпизода 1 играется в браузере, ставится
как приложение (PWA) и работает офлайн.

## Запуск (локально)
Из корня `novella/zaryanka` (чтобы были видны и `vn/`, и `assets/`):

    python3 -m http.server 8080
    # открыть http://127.0.0.1:8080/vn/index.html

> Service worker (офлайн + установка) требует **HTTPS или localhost** — по
> `file://` и по голому HTTP на внешнем хосте он не активируется.

## Состав
| файл | роль |
|---|---|
| `index.html` | каркас: титры, сцена, окно диалога, финал |
| `style.css` | вёрстка 16:9, тёмная тема, красный акцент (как логотип) |
| `app.js` | движок: кроссфейд фона, спрайт, печатная машинка, переходы |
| `scenes.js` | данные эпизода 1 (генерируются `../_vn_build.py` из `scenario.json`) |
| `manifest.webmanifest` | PWA: имя, иконки, `standalone`, `landscape` |
| `sw.js` | офлайн-кеш оболочки и ресурсов эпизода |
| `icons/icon-192.png`, `icons/icon-512.png` | иконки (из логотипа, вариант B) |

## Управление
- **клик / пробел / Enter / →** — далее (первым нажатием «допечатывает» реплику);
- титры и финал — кнопка «Начать» / «Начать заново».

## Что уже есть и что подменяется
- Фоны взяты из сгенерированного арта (`assets/gen/ok_*`), аллея — процедурная
  заглушка `assets/bg_alley.png`.
- Спрайты: `kate_overalls`, `kate_sad`, `sergey`. Остальные персонажи — без фигуры
  (появятся, когда сгенерируем комплект).
