# Зарянка — VN эпизод 1 (Пролог + Приёмная)

Рабочая сборка визуальной новеллы. **Мок `../vn/` не трогаем** — это старая версия.

## Что внутри
- `index.html` — движок (без зависимостей).
- `style.css` — оформление (тёмная тема, красный акцент).
- `app.js` — логика: фон-кроссфейд, спрайты, печатная машинка, видео-узел, тумблеры,
  навигация вперёд/назад (клик, `←`/`→`, свайп), авто-режим, экран конца серии.
- `content.js` — контент эп-1 (генерируется `../_vn2_build.py`, вручную не править).
- `img/` — кадры пролога (`prolog/s1..s7.png`, грейд «тёплый архив»), фон приёмной, спрайты, логотип.

1. **титул** — заставка.
2. **значок** — видео `../out/znak3d_rot_draft.mp4` (единственный видеоассет).
3. **пролог S1..S7** — кадр + дословный авторский текст + закадр (Charon).
4. **приёмная** — фон-кабинет + спрайты Сергея/Екатерины + дословный текст (диалог/нарратив).

## Тумблеры (правый верх, независимы)
| кнопка | что |
|---|---|
| **Авто** | авто-режим: страницы сами перелистываются (по длине текста; если идёт голос — ждёт его) |
| **⏸/▶** | пауза/продолжить (видна только в авто): замораживает таймер + голос + печать текста; резюм с того же места |
| **Aa** | текст-подстрочник (бокс) вкл/выкл |
| 🎙 | голос закадра вкл/выкл |
| ♪ | музыка вкл/выкл |

Глухие читают текст; кому мешают голоса — выключают звук; кто хочет слушать — выключает текст.
Тулбар доступен на **всех** экранах (титул, видео, сцена, конец серии) — авто и тумблеры
можно выставить заранее. «Авто» нужно **включить** (красный) — по умолчанию оно выключено.

## Управление
- **далее**: клик по экрану / `пробел` / `Enter` / `→` / стрелка «›» справа
- **назад**: `←` / `Backspace` / стрелка «‹» слева (на первой странице неактивна)
- **свайп** влево/вправо (тач) — далее/назад
- **`P`** — пауза/продолжить (в авто)
- `Esc` — пропустить видео-значок / выйти из кинозала / на экране конца — в меню

## Конец серии
На последней странице игра **не виснет и не запускает тизер сама** — показывается экран
«Конец первой серии → Ждите следующих серий» с кнопками **В меню** (главный экран)
и **▶ Тизер** (AVM, по желанию).

## Параметры URL (для скриншотов/отладки)
`?node=N` — сразу к узлу · `&page=K` — страница внутри узла · `&auto=1` — сразу авто-режим ·
`&pause=1` — сразу на паузе · `&instant=1` — без анимаций/печатной машинки ·
`&text=0` `&voice=0` `&music=0` — тумблеры. `node=99` — экран конца серии (для скриншота).

Узлы: 0 титул · 1 значок · 2 s1 · 3 s2 · 4 s3 · 5 s4 · 6 s5 · 7 s6 · 8 s7 · 9 приёмная.

## Предзагрузка (app.js)
Кадры, голос и видео качаются **заранее**, пока зритель на титуле — на сцене они
берутся из памяти и не мигают. Список ассетов НЕ хардкодится: он собирается
из `content.js` (`nd.bg`, `pg.cast`, `pg.vo`, `D.chars`, `D.music`), так что новый
контент подхватывается сам.

- Очередь с приоритетами, 4 параллельных запроса. Порядок: логотип + значок-видео + S1 →
  остальной пролог → Приёмная → все эмоции спрайтов → музыка и тизер (9.7 МБ, самый низ).
- Каждая страница при показе поднимает вперёд следующие 6 (`plWarm`) — впёрёд идём всегда готовыми.
- Голос/музыка/видео качаются как `blob:` — играются из памяти, без сетевой паузы.
- На титуле — тонкая полоса + «загрузка N%». Кнопка «Начать» ждёт только **критичное**
  (значок + S1 + его голос), макс. 12 с; **повторный клик — начать сразу**.
- `?preload=0` — выключить (и `?node=N` — режим скриншотов — выключает автоматически;
  если в шот-режиме нужна загрузка: `?node=N&preload=1`).
- Диагностика: `window.__PL` (`img`/`aud`/`vid`/`miss`/`queue()`) и `window.__DBG` (`pos`, `node`).
- Тесты: `python3 _js_check.py` (синтаксис/исключения) · `python3 _pl_verify2.py` (главное:
  после предзагрузки листание страниц не создаёт НИ ОДНОГО сетевого запроса) ·
  `python3 _pl_slow.py` (поведение на 2 Мбит/с, снимки `_pl_slow_*.png`).
  Браузер для тестов — `_cdp.py` (мини-CDP без зависимостей), локальный сервер поднимается там же.
