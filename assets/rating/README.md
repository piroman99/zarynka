# Рейтинг генераторов картинок («Зарянка»)

**Методика:** один и тот же промпт (поясной портрет Зарянки-космонавта, аниме-VN-стиль),
для каждого генератора — ближайшие доступные параметры (портретный кадр 3:4, 1K).
Фиксировались: результат, цена за кадр, время генерации. Сборка: `rating.py` → `rating_sheet.py`.

**Вывод для проекта:** для массовых кадров брать `grok-imagine` (2.02 ₽) или `qwen3-image`
(2.59 ₽) — аниме-попадание как у gpt-image-2, но дешевле и быстрее. `gpt-image-2` держать там,
где нужен image-to-image с референсом лица. Дорогие модели (flux-2-max, nano-banana-pro, 7–12 ₽)
оправданы только для «обложечных» кадров. z-image/recraft/imagen4 — не наш стиль.
