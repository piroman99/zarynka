## Конвейер

1. `python3 art.py` — сгенерировать фоны-заглушки.
2. `python3 scenario.py` — выгрузить `scenario.json`.
3. `python3 frames.py` — собрать кадры-превью.
4. `python3 gen.py <сцена> [--ref <img>]` — генерация арта через PlusVibe → `assets/gen/`.
5. `python3 review_sheet.py` — собрать контрольный лист для сверки. 
6. (план) рендер видео: кадры → `ffmpeg` (imageio-ffmpeg) → MP4/WebM.

## Выбор генератора (2026-10-10)

Заказчик выбрал **flux-2** как ближайший к своему виденью (nano-banana — тоже ок; gpt-image-2 —
«слишком идеальный и смазливый»). В `gen.py` дефолт-модель = `flux-2`, добавлен стиль-режим
`--simple` («попроще», ретро-гальгэ). `gpt-image-2` держим только там, где нужен i2i с референсом лица.
**Устойчивость образа:** чистый текст не держит лицо; повторять утверждённый кадр надо через
image-to-image с ним же как референсом. Метрика (MAE↓ к утверждённой Екатерине):
**nano-banana-2.1 i2i = 8.5**, grok-imagine i2i = 13.0, flux-2 i2i = 19.0, flux-2 по тексту = 36.1,
2016-спрайт = 60.0. Лист: `assets/review/review_08_kate_repro.png`.
