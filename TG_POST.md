# «Зарянка» в Telegram

**Канал:** https://t.me/zaryanka_vn (создан Иваном 2026-10-18).
Публикация: `tg.py` (stdlib, Bot API) + `_tg_post_e.py` (текст первого поста).

## Что нужно один раз

1. **Бот.** `@BotFather` → `/newbot` → имя и `@username` (например `zaryanka_vn_bot`) → токен вида `123456789:AA…`.
2. **Права.** В канале: «Управление» → «Администраторы» → добавить бота, включить
   «Публикация сообщений» (+ «Редактирование» и «Закрепление», если нужно).
3. **Токен в файл** (из своего терминала, не через агента):
   ```sh
   printf '%s' 'ВСТАВИТЬ_ТОКЕН' > ~/.nanobot/workspace/novella/zaryanka/.tg_token
   chmod 600 ~/.nanobot/workspace/novella/zaryanka/.tg_token
   ```
4. **Сеть для агента — РЕШЕНО, allowlist не нужен (проверено 2026-10-19).** Это блокировка
   РКН/DPI у провайдера, а не песочница: DNS `api.telegram.org` резолвится (149.154.166.110),
   локального прокси/файрвола нет, в nanobot нет egress-allowlist — добавлять некуда и нечего.
   Симптом ровно один: TCP до DC Telegram флапает (таймаут, со второй попытки TLS 1.3 OK).
   `tg.py` ходит на IP с `server_hostname=api.telegram.org` + `Host: api.telegram.org`
   и ретраит (`149.154.167.220`, `149.154.167.197`, `149.154.175.50`; переопределяется `TG_API_IPS`).
   Никакой VPN/SSH-туннель/Browsec не нужен — расширения помогают только твоему браузеру.
   Настоящий обход (если флап достанет) — прокси/VPN на хосте, а не запись в allowlist.

## Команды

```sh
python3 tg.py whoami                     # бот + канал (id, название, описание, подписчики)
python3 tg.py info                       # описание/название/подписчики канала
python3 tg.py desc "<текст>"             # описание канала (бот-админ)
python3 tg.py title "<название>"         # переименовать канал
python3 tg.py post "<текст|@file>" [--video f] [--photo f] [--silent]
python3 tg.py edit <message_id> "<текст|@file>"
python3 tg.py pin <message_id>

python3 _tg_post_e.py                    # первый пост с тизером (12.7 МБ, 30 с)
python3 _tg_post_e.py --text             # то же без видео
```

Текст — в HTML-разметке Telegram (`<b>…</b>`, `<i>`, `<a href>`), ссылки не превью-картинкой
по умолчанию включены.

## Отличия от ВК

| | ВК | Telegram |
|---|---|---|
| Токен | групповой `.vk_token` | бот-админ `.tg_token` |
| Опросы | `polls.create` только user-токеном | нативные опросы бота (`sendPoll`) — **можно** |
| Видео в посте | только user-токен | **можно** ботом, до 50 МБ |
| Аватар/обложка канала | только user-токен | ботом нельзя, только руками |
| Чтение стены | `wall.get` запрещён групповому → headless DOM | `getChat` работает |

Первый эпизод собран — не макет и не раскадровка:

Превью открывается в браузере, ставить ничего не нужно:

## Идеи для следующих постов (TG)

- значок-3D: 5-секундный луп + одна строка про гравировку `ЛМД`;
- голоса: короткий фрагмент реплики Екатерины (11 сек) и закадра — «угадайте, кто говорит»;
- кадр S7 (очередь у приёмной) и одна фраза Старика;
- нативный опрос бота: «Луна или Марс?» (в TG это делается ботом, в отличие от ВК).
